# Bed Time

Cuento interactivo para dormir. Acompaña a Olivia y a su amiga la oca durante una noche de aventuras.

## Cómo abrirlo

Abre `index.html` en el navegador. Puedes avanzar o retroceder con los botones, con las flechas del teclado o deslizando en una pantalla táctil.

El cuento tiene nueve páginas ilustradas y sonido que puedes activar o silenciar.
